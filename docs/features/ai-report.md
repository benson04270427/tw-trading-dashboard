# AI 盤後日報

收盤後由你選擇的 AI 模型，根據衡析當天彙整的數據寫成一份結構化日報：盤勢重點、自選股逐檔短評、以專業投資顧問角度撰寫的明日觀察，並可下載 9:16 盤後籌碼整理圖卡。

## 在哪裡

- 電腦版：「今日焦點」頁頂端；排程設定在「資料與設定 → AI 盤後日報排程」。
- 手機版：「焦點」分頁頂端，可切換日期、下載圖卡、立即產生；完成後推播通知。

## 日報內容

| 段落 | 內容 |
|---|---|
| 標題與總結 | 一句話標題，2–4 句盤勢總結 |
| 分段重點 | 大盤與資金板塊、法人與期權籌碼（有資料時）、盤中異動回顧、型態與題材；每段 2–5 個附數字的重點 |
| 值得注意 | 今天真正值得注意的自選或研究股（最多 6 檔）與原因 |
| 自選股逐檔 | 每檔自選股一則（最多 30 檔）：當天走勢、量能、籌碼（大戶、追蹤分點）與觸發的提醒，標示偏多／中性／偏空 |
| 明日觀察 | 4–6 則總體市場分析，見下一節 |
| 風險提醒 | 2–4 則總體層面的風險 |
| 圖卡重點 | 印在 9:16 圖卡上的精簡重點與明日觀察 |

### 明日觀察的寫法

以專業投資顧問的角度整理下一個交易日該注意的整體市場面向，每則以下列標籤開頭並依重要性排序：

- 【大盤】指數漲跌、成交量能較前日的變化、漲跌家數與資金集中的板塊。
- 【法人籌碼】三大法人現貨買賣超的方向與規模，與指數是否背離。
- 【期權】外資台指期淨未平倉與增減、選擇權買權／賣權部位與 P/C 比、散戶小台與微台多空比。
- 【資金面】融資餘額增減（槓桿）與融券變化。
- 【國際】今晚美國公布的經濟數據（附預估值與前值，說明優於或差於預期的可能影響）與重要財報。
- 【行事曆】明日盤中公布的數據、休市或其他已知事件。

每則要引用數字、說明為什麼重要，並給「若…則…」的情境判斷。**不預測個股明天的走勢**；個股只在影響大盤的權值股或美股財報公司時提及。

## 給模型的資料

| 資料 | 來源 |
|---|---|
| 資金板塊、大盤成交與漲跌家數 | [資金熱浪](heatmap.md)（沒有當日熱浪時先查一次） |
| 加權／櫃買指數、期貨近月、融資券、散戶小台／微台多空、選擇權 P/C | FinMind（與圖卡同一份，約 11 次請求，30 分鐘內沿用） |
| 三大法人、外資期權部位 | [法人／期貨籌碼](flows.md)（沒有當日紀錄時先查一次） |
| 盤中異動與自訂提醒 | [盤中雷達](live-radar.md)、[自訂提醒](price-alerts.md) |
| 自選股：報價、高低、量比、大戶週變化、追蹤分點進出 | 即時看板、[大戶集中度](big-holders.md)、[分點追蹤](broker-watch.md) |
| 研究名單漲跌前 5、型態訊號 | 研究總覽、[型態選股](patterns.md) |
| 焦點新聞、今晚到明晨的國際數據與美股財報、本周行事曆 | [今日焦點](briefing.md) |

模型只能根據這些資料撰寫；資料缺漏時要寫明缺什麼，不得推測數字。日報在 16:30 產生，分點資料約 18:00 才公布，因此日報中的分點進出是前一個交易日的資料；大戶資料為最近一週。

## 排程與產生

- 預設平日 16:30 自動產生並推播（可改時間或關閉）；當天沒有盤中監控紀錄（休市或監控關閉）時不自動產生。
- 自動產生失敗會在 20 分鐘後重試，同一天最多 3 次。
- 可隨時按「產生今日日報」或「重新產生」。
- 可查看最近 30 天的日報。

## 推理模型與費用

- 支援 Anthropic Claude、OpenAI、Google Gemini，以及任何 OpenAI 相容端點（包括本機模型）；在「資料與設定 → 推理模型」設定服務、金鑰與模型。
- 一份日報約使用數萬 input tokens，費用依所選服務的定價計算；日報頁尾會顯示實際用量。

## 9:16 圖卡

收盤籌碼整理圖卡（PNG）：指數、三大法人、市場寬度、台指期與選擇權、散戶籌碼、融資融券、期貨市場、類股強弱，以及日報的圖卡重點。電腦版按「📊 下載圖卡」，手機版按「📊 下載 9:16 圖卡」。

## 注意事項

- 偏多／中性／偏空描述的是資料呈現的技術與籌碼狀態，不是建議。
