# 風控配方回測

用 8～10 年的歷史資料，比較[風控水位](risk-gauge.md)不同的指標權重（配方）換算成建議持股後，績效與訊號命中率哪一組比較好。評分方式和風控水位完全相同（各指標和過去 250 個交易日比較的百分位，大盤趨勢用乖離規則），只換權重。

> 回測是用過去的資料，不保證未來有效，也不是買賣建議。

## 怎麼用

目前以 API 執行（畫面待加入）：

- `POST /api/risk/backtest`：開始回測（台股約 1～2 分鐘，美股約 30 秒）。
- `POST /api/risk/optimize`（台股）：權重最佳化，結果在 `GET /api/risk/backtest` 的 `optimize`。
- `GET /api/risk/backtest`：回傳進度（`job`）、上一次的配方比較（`result`）與權重最佳化（`optimize`）。

## 配方

| 市場 | 配方 | 權重或做法 | 出處 |
|---|---|---|---|
| 台股 | 目前權重 | 融資 29、外資選擇權 29、外資期貨 5 日增減 14、匯率 14、趨勢 14 | 衡析現行設定（2026-10-24 最佳化） |
| 台股 | 舊權重 | 散戶 20、融資 15、外資期貨 20、外資現貨 15、匯率 10、趨勢 20 | 2026-10-24 以前的設定 |
| 台股 | 等權重 | 六個指標一樣重 | CNN 恐懼與貪婪指數的做法 |
| 台股 | 趨勢為主 | 趨勢 50，其餘各 10 | 均線擇時（Faber） |
| 台股 | 只看趨勢 | 趨勢 100 | 對照組 |
| 台股 | 外資主導 | 外資期貨 35、外資現貨 35、趨勢 30 | 政大碩論（2011）：外資風險胃納對月報酬較有解釋力 |
| 台股 | 散戶反指標 | 散戶 40、融資 30、趨勢 30 | 小台散戶多空比當反指標 |
| 台股 | 只看籌碼 | 目前權重拿掉趨勢 | 對照組 |
| 台股、美股 | 目前權重＋平滑 | 目前權重，分數取近 5 日平均 | 減少建議持股來回跳動 |
| 美股 | 目前權重 | VIX 20、期限結構 10、信用利差 20、殖利率 10、美元 10、廣度 10、趨勢 20 | 衡析現行設定 |
| 美股 | 等權重 | 七個指標一樣重 | CNN 的做法 |
| 美股 | CNN 式 | 趨勢、廣度、VIX、信用利差、期限結構等權 | CNN 七指標中可取得的五項 |
| 美股 | 趨勢為主／只看趨勢 | 同台股 | 均線擇時 |
| 美股 | 信用與波動 | 信用利差 35、VIX 25、期限結構 20、趨勢 20 | 常見的 risk-on／risk-off 指標 |
| 美股 | 不含趨勢 | 目前權重拿掉趨勢 | 對照組 |
| 美股 | 情緒反向＋趨勢 | 情緒與總經指標反向（越恐慌分數越低），趨勢照常 | CNN 指數回測：中度恐懼後 21 日勝率約 7 成 |

## 台股權重最佳化

| 項目 | 規則 |
|---|---|
| 指標 | 風控水位的 8 個台股指標（含參考不計分的 3 個） |
| 組合 | 每個指標權重 0、1、2，全部 6,560 組 |
| 挑權重期間 | 2024 年以前（約 2018-10～2023-12） |
| 驗證期間 | 2024 年以後；只看挑權重期間的表現排名，再檢查驗證期間是否一樣好 |
| 預測力 J | −相關係數 ＋ 高風險命中率相對平常的優勢 ＋ 低風險命中率相對平常的優勢（訊號少於 5% 的日子要扣分） |
| 結果 | 每個指標單獨的預測力、前 12 名組合、兩段期間都好的穩健組合，以及完整期間的績效（扣成本、有無 5／10 日平均） |

2026-10-24 的結果：單一指標中「外資選擇權淨部位」在兩段期間都最好；「外資台指期淨部位」在 2024 年前方向相反、2024 年後很準，不穩定，所以改用它的 5 日增減。挑權重期間第 1 名（融資 2、外資選擇權 2、外資期貨 5 日增減 1、匯率 1、趨勢 1）在驗證期間也維持領先，已用於[風控水位](risk-gauge.md)。

## 計算方式

| 項目 | 規則 |
|---|---|
| 持股 | 每天收盤依分數換算建議持股（20%～90%，與風控水位相同），賺下一個交易日的指數報酬；沒持股的部分報酬 0 |
| 換檔成本 | 每次調整持股，扣掉調整比例 × 成本：台股 0.585%（手續費 0.1425% × 2 ＋ 證交稅 0.3%），美股 0.1% |
| 績效 | 年化報酬、最大回撤、年化波動、夏普值（無風險利率以 0 計）、平均持股 |
| 調整時機的加分 | 夏普值減去「同樣平均持股、但固定不動」的夏普值；大於 0 代表調整時機有幫助 |
| 高風險命中率 | 分數 ≥ 60 之後 20 個交易日指數下跌的比例（和全部日子的下跌比例比較） |
| 低風險命中率 | 分數 < 40 之後 20 個交易日指數上漲的比例 |
| 相關係數 | 分數和之後 20 日報酬的排名相關（越負代表分數越能預警） |
| 換檔次數 | 建議持股改變的天數 |
| 分級表現 | 五個風險等級各自之後 20 日的平均報酬、上漲比例、期間最大跌幅 |
| 綜合排名 | 夏普值、調整時機的加分、兩個命中率、相關係數、最大回撤各自排名後平均 |

## 資料來源與請求量

與風控水位相同的來源，期間拉長：台股 FinMind 8 個請求（約 9 年），美股 FRED／Cboe／Nasdaq 9 個免金鑰請求（約 11 年）。結果存在 `risk/backtest.json`（台股在 `.local/`，美股在 `.local-us/`）。

## 注意事項

- 台股加權指數是價格指數，不含股利（每年約 3～4%），買進持有的實際報酬會比表中高。
- FRED 的高收益債利差只提供近 3 年，美股回測較早的期間沒有這個指標（以其他指標的權重計算）。
- 指標要先累積 250 個交易日才開始評分，所以回測起點比資料起點晚約一年。
