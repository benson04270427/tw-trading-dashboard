# 策略回測

把衡析的幾套規則套到歷史資料上，看平均報酬、勝率與最大回撤：

- [訊號面板](signal-panel.md)的 ATR 追蹤線
- [策略選股](strategy-zones.md)的價值區、升溫區
- [每日精選](daily-picks.md)

台股、美股都有。

> 不含手續費、稅與滑價。過去績效不代表未來，也不是買賣建議。

## 在哪裡

- **電腦版**：左側 RESEARCH 區的「策略回測」。
- **手機版**：「型態」分頁的「策略選股」下方。

## 回測規則

| 策略 | 進場 | 出場 | 資料 |
|---|---|---|---|
| ATR 追蹤線翻多（研究名單） | 追蹤線翻多那天的收盤價（只做多） | 盤中跌破停損（進場價 − 1.5 倍 ATR，跳空時以開盤價計）或追蹤線翻空那天的收盤 | 研究名單每檔的本機日 K（約 1～2 年），參數與訊號面板相同 |
| 價值區、升溫區 | 入選當天的收盤價 | 持有固定交易日數後的收盤價（預設 20，可選 5／10／20／60） | 每天保存的入選名單＋收盤熱浪圖 |
| 每日精選 | 同上 | 同上 | 每天保存的精選＋收盤熱浪圖 |

入選策略從開始保存名單、熱浪圖的那天起累積。還沒滿持有天數的交易列為「持有中」，不計入統計。

## 統計

| 指標 | 計算 |
|---|---|
| 交易筆數、勝率 | 已出場的交易；報酬 > 0 為勝 |
| 平均報酬、中位數 | 每筆交易的報酬 % |
| 獲利因子 | 獲利交易報酬合計 ÷ 虧損交易報酬合計的絕對值 |
| 組合報酬 | 每天把資金平均分配給持有中的部位（沒有部位時持有現金），每日報酬連乘 |
| 最大回撤 | 組合權益曲線從前高的最大跌幅 |
| 比較基準 | 同期間的加權指數或 S&P 500 報酬，也畫在權益曲線圖上 |

樣本少於 20 筆時標示「參考性有限」。每張卡片下方可展開最近 12 筆交易。

## 運作方式

- 每天第一次開啟時自動計算，結果存在 `.local/backtest.json`；按「重新計算」可換持有天數重算。
- 只用本機資料，不發出網路請求。
