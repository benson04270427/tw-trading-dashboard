# 型態選股

在最近 90 個交易日內辨識 10 種經典技術型態，並為每個型態附上條件式的進場帶、防守價與量度目標。

## 在哪裡

- 電腦版：左側選單「型態選股」。
- 手機版：「型態」分頁。

## 型態

| 類別 | 型態 |
|---|---|
| 反轉型 | 頭肩底、雙底、三重底、圓底、下降楔形 |
| 整理突破型 | 上升三角形、突破平台 |
| 延續型 | 旗形、旗竿三角形、杯柄 |

類別由型態決定：反轉型是下跌或盤整後在低檔做出底部、突破頸線由弱轉強；延續型是先有一段上漲、短暫整理後再往上突破；整理突破型是在固定壓力下橫盤或低點墊高後突破區間上緣。在清單選擇類別時，畫面會顯示這段說明。

## 清單中的型態縮圖

清單每一筆都有一張 90 日 K 線縮圖（紅漲綠跌，與點開後的大圖相同的價格尺度換算），不用點進去就能看出為何判定為這個型態：

| 圖上元素 | 意義 |
|---|---|
| 淺色底 | 型態區間（型態開始到結束的交易日） |
| 琥珀虛線 | 頸線／壓力 |
| 綠色虛線 | 結構支撐（楔形、三角形為支撐趨勢線） |
| 青色圓點 | 辨識出的轉折點（壓力、支撐觸點） |

## 籌碼備註

確認狀態旁會列出這檔股票近期的籌碼狀況（有資料才顯示），紅色偏多、綠色偏空：

| 備註 | 條件 | 資料來源 |
|---|---|---|
| 千張大戶 4 週 ±x%（籌碼集中／渙散） | 最新一週千張大戶持股比例與約 4 週前相差 ≥ 0.5 個百分點，且股東人數同向減少／增加 | [大戶集中度排行](big-holders.md)的全市場股權分散表（需已取得紀錄） |
| 法人近 20 日買超／賣超 x 億 | 近 20 個交易日三大法人淨額 × 當日收盤累計，絕對值 ≥ 1 億元 | [法人資金板塊](instflow.md)的日檔（需已按過「更新資料」） |
| 外資／投信連買（連賣）N 天 | 連續 3 個交易日以上同方向；達到已存天數上限時顯示「N 天以上」，今天金額大於昨天時加 ↑ | 同上 |

備註只呈現事實，不改變型態判定與強度分數。

縮圖下方（手機版）或滑鼠移到縮圖上（電腦版）會顯示判定理由，例如「2 個相隔至少 10 日的低點差距 0.2%」。縮圖不含成交量；點開可看完整 K 線、成交量與條件式計畫。

## 狀態

| 狀態 | 條件 |
|---|---|
| 接近突破 | 價格接近壓力／頸線，尚未突破 |
| 突破待量確認 | 已收盤突破，但突破日成交量未達前 20 日均量 1.3 倍 |
| 突破待次日確認 | 今天放量突破，需看次日是否守住頸線 |
| 量價確認 | 收盤高於頸線加 0.15 ATR，突破量 ≥ 1.3 倍，之後沒有跌回 |

突破後收盤跌回頸線下方 0.35 ATR 視為假突破，型態不再列出。

## 強度分數（0–100）

型態幾何品質（最高 40）＋確認程度（量價確認 30、已突破 18、接近 8）＋突破量能（最高 20）＋收盤在 20 日均線之上（10）。

## 條件式計畫

| 項目 | 計算 |
|---|---|
| 進場帶 | 頸線加 0.2–0.75 ATR |
| 結構防守 | 支撐下方 0.25 ATR |
| 量度觀察位 | 頸線加型態高度（非目標價） |
| 報酬風險比 | 扣除約 0.6% 交易成本後計算；低於 1.5 時建議暫不進場 |

價格已超過進場帶時標示「不追價，等待回測」。計畫中列出尚未核對的事項（法說、財報、除權息等）。

- 站上進場價、跌破結構防守會出現在[盤中雷達](live-radar.md)。

## 掃描範圍與資料

- 台股：上市櫃普通股，排除金融、水泥、造紙、紡織、運動休閒、貿易百貨、油電燃氣、文化創意等股性不適用的產業，以及 ETF、權證；五日平均成交量至少 300 張。
- 資料源支援全市場單日行情時掃描整個市場（每日更新後自動執行，也可以手動「更新型態資料」）；否則只掃描研究名單與自選股的本機資料。
- 90 個交易日的還原與原始價格必須完整對齊，缺日的股票不列入。

## 注意事項

型態是條件式的技術計畫，需要等條件成立；不代表會上漲，也沒有考慮你的帳戶風險額度。
