# 型態分區

把台股科技股依技術型態分組，像型態圖鑑一樣：每個型態一張卡片，顯示小圖示、偏多／偏空／中性、性質（反轉、延續、整理）與目前符合的檔數；點開看是哪些股票，點股票看 K 線。一檔股票可以同時屬於多個型態。

> 型態是常見的技術分析分類，同一段走勢常可以有不同解讀；分數是型態吻合程度，不是勝率，也不是買賣建議。

## 在哪裡

- **電腦版**：左側選單「研究」→「型態分區」（只在台股市場顯示）。
- **手機版**：「型態」分頁上方切到「型態分區」。

## 怎麼用

1. 上方選範圍：電子科技（預設）、AI 供應鏈、全市場。
2. 用「全部／偏多／偏空／中性」篩選型態卡片。
3. 點型態卡片，列出符合的股票：收盤、漲跌、吻合分數（0～100）、關鍵價（頸線、支撐、壓力、上下緣等）與也符合幾種其他型態。
4. 點股票開 K 線（電腦版）或報價（手機版）。

## 型態

| 組別 | 型態 | 偏向 |
|---|---|---|
| 支撐壓力 | 水平壓力、水平支撐 | 中性 |
| 趨勢線 | 上升趨勢線／下降趨勢線 | 偏多／偏空 |
| 常見型態 | W 底・雙底／M 頂・雙頂 | 偏多／偏空 |
| 常見型態 | 上升三角・水平壓力／下降三角・水平支撐 | 偏多／偏空 |
| 常見型態 | 對稱三角收斂、箱型・水平整理 | 中性 |
| 反轉型態 | 頭肩底、三重底／頭肩頂、三重頂 | 偏多／偏空 |
| 整理與延續 | 下降楔形、上升通道、多頭旗形 | 偏多 |
| 整理與延續 | 上升楔形、下降通道、空頭旗形 | 偏空 |
| 整理與延續 | 擴散三角・喇叭口 | 中性 |
| 價格路徑 | V 型反轉向上、圓弧底、杯柄・向上路徑、突破後回踩、高低點階梯上升 | 偏多 |
| 價格路徑 | 倒 V 反轉向下、圓弧頂、倒杯柄・向下路徑、跌破後反抽、高低點階梯下降 | 偏空 |
| 諧波比例 | 加特利 Gartley、蝙蝠 Bat、蝴蝶 Butterfly、螃蟹 Crab（各分多、空） | 偏多／偏空 |

## 運作方式

| 項目 | 規則 |
|---|---|
| 資料 | [型態選股](patterns.md)的全市場快照：最近 90 個交易日的日 K（有還原價時用還原價） |
| 範圍 | 電子科技：證交所／櫃買產業別為半導體、電腦及週邊、光電、通信網路、電子零組件、電子通路、資訊服務、其他電子、數位雲端；排除近 20 日平均成交量不到 300 張的股票 |
| 轉折點 | zigzag：價格從前一個轉折反向超過門檻才算新的高點或低點；門檻 ＝ 近 14 日 ATR% × 2，介於 4%～12% |
| 支撐／壓力 | 至少兩個轉折低點（高點）在 2% 內，目前價距離 10% 以內 |
| 趨勢線 | 最近 2～3 個低點（高點）依序墊高（降低）、跨 15 根以上、斜率每根 0.05% 以上，期間收盤沒有跌破（突破）3% 以上，目前價在線上方（下方）12% 以內 |
| 雙底／雙頂 | 低 高 低（高 低 高），兩底（頂）差 4% 內、相隔 10 根以上、中間反彈（回檔）6% 以上，第二個底（頂）在最近 30 根內，且之前有一段下跌（上漲） |
| 頭肩 | 五個轉折，頭比兩肩低（高）3% 以上、兩肩差 6% 內、右肩在最近 30 根內；頸線突破（跌破）時加分 |
| 三重底／頂 | 三個低點（高點）差 4% 內，中間兩個高點（低點）差 8% 內 |
| 三角、楔形、通道、箱型 | 最近 60 根內至少 5 個轉折、跨 20 根以上；依上緣與下緣斜率（每根 ±0.06% 為水平）與寬度變化（收斂 < 75%、擴散 > 133%）分類，目前價仍在上下緣附近 |
| 旗形 | 最近 40 根內 15 根以內漲（跌）15% 以上的旗竿，之後至少 4 根整理、回檔（反彈）8%～50% 且沒有創新高（低） |
| V 型 | 最近 30 根的最低（最高）點，前 20 根跌（漲）15% 以上，之後收復 60% 以上 |
| 圓弧 | 最近 90 根收盤的二次曲線擬合度 ≥ 0.6、頂點在中段、深度 8% 以上 |
| 杯柄 | 兩個杯緣差 5% 內、杯深 12%～45%、右杯緣在最近 3～20 根，之後的柄回檔（反彈）3%～34% 杯深 |
| 突破後回踩 | 前段（倒數 80～25 根）高點（低點）被收盤突破（跌破）2% 以上、之後拉開 5% 以上，目前回到該價位 −3%～+4% |
| 階梯 | 最近 3 個高點與 3 個低點都依序墊高（降低），最後一個轉折在最近 25 根內 |
| 諧波 | 最後 5 個轉折（XABCD），D 在最近 10 根內；AB/XA、BC/AB、CD/BC、AD/XA 落在各型態的比例範圍（Gartley AD ≈ 0.786、Bat ≈ 0.886、Butterfly 1.27～1.618、Crab ≈ 1.618） |

- 每檔依所有符合型態的偏向加總，判斷整體偏多、偏空或中性（某一邊比另一邊多 20% 以上）。

## 資料來源與請求量

不另外請求；使用型態選股的全市場快照（證交所、櫃買每日收盤行情，每天收盤後自動更新，或在「型態選股」手動更新）。結果在記憶體中快取，快照更新或換日時重新計算。

## 注意事項

- 型態資料剛更新時需要約 90 個交易日的完整資料；快照沒準備好時頁面會提示到「型態選股」更新。
- 價格路徑與諧波型態對門檻很敏感，同一段走勢在不同波動度下可能被歸到不同型態。
- 目前只支援台股。
