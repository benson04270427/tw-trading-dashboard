# 低估選股

在全市場（上市＋上櫃）找出**比同業便宜、但獲利與營收沒有轉壞**的公司。以本益比、股價淨值比、殖利率、估算 ROE 與月營收成長評分，有三種策略可選。只支援台股，資料免金鑰。

> 低估選股是研究的起點，不是買賣建議。低本益比可能來自一次性獲利或產業循環高點，請搭配財報與產業狀況判斷。

## 在哪裡

- 電腦版：左側「RESEARCH → 低估選股」。
- 手機版：「型態」分頁上方切換到「低估選股」。

## 怎麼用

1. 選擇策略：**低估價值**、**成長合理價**或**高殖利率**。
2. 視需要調整「成交金額 ≥」門檻（不限、500 萬、1,000 萬〔預設〕、3,000 萬、1 億），排除冷門股。
3. 每張卡片顯示分數、本益比（與同業中位數）、淨值比、殖利率、ROE、今年累計營收年增、收盤價，以及符合的理由（✓）與要留意的地方（⚠）。
4. 按股票名稱開啟個股視窗；按 ☆ 加入自選。

## 運作方式

基本條件：本益比 > 0（有獲利）、有股價淨值比、成交金額達門檻。

| 分項 | 計算 | 比較範圍 |
|---|---|---|
| 便宜 | 本益比與淨值比百分位的反向平均 | 同產業（同業少於 6 檔時改與全市場比較） |
| 品質 | 估算 ROE ＝ 淨值比 ÷ 本益比 | 全市場 |
| 成長 | 最新單月營收年增與今年累計營收年增的百分位平均 | 全市場 |
| 收益 | 殖利率百分位 | 全市場 |

| 策略 | 權重（便宜／品質／成長／收益） | 門檻 |
|---|---|---|
| 低估價值 | 50／25／15／10 | 本益比 ≤ 25、ROE ≥ 8%、累計營收年增 ≥ −15% |
| 成長合理價 | 35／20／45／0 | 累計營收年增 ≥ 15%、PEG（本益比 ÷ 累計營收年增）≤ 1.2、ROE ≥ 10% |
| 高殖利率 | 15／25／10／50 | 殖利率 ≥ 5%、ROE ≥ 8%、累計營收年增 ≥ −10% |

分數 0～100，依權重加總後由高到低排列，電腦版顯示前 60 檔、手機版前 40 檔。

**提醒標記（⚠）**：最新單月營收年減 20% 以上、本益比低於 6、殖利率 10% 以上、成交金額未滿 3,000 萬。

## 更新

- 平日 **18:40** 後自動更新一次；按「更新資料」可隨時重新取得（約 30 秒）。
- 第一次啟動衡析時若還沒有資料，會先取得一次。
- 切換策略或成交金額門檻時直接用已取得的資料重新計算，不另外查詢。

## 資料來源與請求量

證交所與櫃買中心開放資料（免金鑰），每次更新 8 個請求：

| 資料 | 上市 | 上櫃 |
|---|---|---|
| 股票清單與產業 | `t187ap03_L` | `mopsfin_t187ap03_O` |
| 本益比、淨值比、殖利率 | `BWIBBU_ALL` | `tpex_mainboard_peratio_analysis` |
| 最新月營收 | `t187ap05_L` | `mopsfin_t187ap05_O` |
| 收盤價與成交金額 | `STOCK_DAY_ALL` | `tpex_mainboard_daily_close_quotes` |

## 注意事項

- 本益比使用近四季 EPS，ROE 是以淨值比 ÷ 本益比估算，與財報的 ROE 可能不同。
- 金融、營建等產業的本益比與淨值比意義和一般產業不同，建議與同業比較時多參考產業特性。
- 月營收約每月 10 日前公布完畢；月初時部分公司仍是上個月的資料。
