# 衡析功能說明

每項功能各有一份說明，內容包括：在哪裡、怎麼用、運作方式、設定、資料來源與請求量、注意事項。
整體介紹、安裝與日常操作見 [README.zh-TW.md](../../README.zh-TW.md)；各版本的變更見 [版本紀錄](../CHANGELOG.zh-TW.md)。

> 衡析是研究工具。分數、提醒、型態與 AI 文字都是研究紀錄，不是買賣訊號、目標價或報酬預測，也不構成投資建議。

## 開盤前

| 功能 | 說明 |
|---|---|
| [今日焦點](briefing.md) | 盤前焦點新聞、本周經濟數據與財報行事曆 |
| [持股健檢](portfolio.md) | 持股損益、權重、產業集中度、相對大盤強弱、實際持股 vs 風控建議、同產業替代候選、除權息行事曆，停損／停利到價提醒（台股、美股） |
| [今日漲跌排行與每日精選](daily-picks.md) | 全市場漲跌幅前 20 名、依籌碼／訊號／量價／營收／新聞挑出的每日 5 檔，☆ 直接加入自選（台股、美股） |

## 研究

| 功能 | 說明 |
|---|---|

| [策略選股與入選紀錄](strategy-zones.md) | 產業／美股價值區與升溫區，每天保存名單，K 線視窗「策略」分頁標出每檔的入選點 |
| [目標價](price-targets.md) | 平均／最高／最低目標價與未來 12 個月區間圖，下方列出各家券商的目標價（新聞擷取＋FactSet／Nasdaq 共識） |
| [財報分析與估價河流圖](financials.md) | 近 12 季營收、利潤率、EPS、ROE、自由現金流、負債比；本益比／股價淨值比 5 年倍數通道與合理價 |
| [股利與除權息](dividends.md) | 歷年配息、現金殖利率、填息天數、下次除息、持股預估股利 |
| [內部人持股與交易](insiders.md) | 台股董監持股逐月增減、質押、申報轉讓（自選／持股有新申報時提醒）；美股 Form 4 交易 |
| [借券賣出與放空](short-interest.md) | 台股借券賣出與融券餘額、回補天數；美股放空股數與回補天數 |
| [同業比較](peers.md) | 同供應鏈或同產業的本益比、淨值比、殖利率、營收與 EPS 成長，排名與中位數 |
| [策略回測](backtest.md) | ATR 追蹤線、價值區、升溫區、每日精選的勝率、平均報酬、組合報酬與最大回撤 |
| [型態選股](patterns.md) | 90 個交易日、10 種型態與條件式進場計畫 |
| [型態分區](shapes.md) | 台股科技股依約 40 種技術型態分組（支撐壓力、趨勢線、雙底雙頂、頭肩、三角楔形、旗形通道、圓弧杯柄、諧波），標示偏多、偏空或中性 |
| [回檔買點](pullback.md) | 強勢股上漲後整理、回到均線與 AVWAP 匯聚的支撐附近：觸發價、停損、可買股數與歷史回測（台股、美股） |
| [總經大地圖](macro-map.md) | 加權指數／S&P 500 近況、依過去十年同期推估的路徑與區間、未來三個月的歷史統計與重點事件，選用 AI 月度展望 |
| [風控水位](risk-gauge.md) | 台股：融資、外資選擇權與台指期、匯率與大盤趨勢（權重經回測最佳化）；美股：VIX、信用利差、利率、美元、市場廣度與 S&P 500 趨勢。換算成風險分數與建議持股水位，附 AI 解讀 |
| [風控配方回測](risk-backtest.md) | 用 8～10 年歷史比較風控水位不同權重配方的績效、最大回撤與訊號命中率（台股、美股） |
| [逆勢布局](contrarian.md) | 和風控水位相反的看法：CNN 恐懼與貪婪、外資情緒、恐慌指標、位階與短線跌深越恐慌，建議持股越高（台股、美股） |
| [低估選股](value-screener.md) | AI 供應鏈（預設）、電子科技或全市場的本益比、淨值比、ROE、殖利率與月營收成長，三種低估策略 |
| [研究族群、自選與話題追蹤](groups-watchlist.md) | 族群管理、自選分組、事件證據判讀 |
