# 五檔錄製器

盤中把即時推播收到的每一次五檔變動（以及逐筆成交）錄下來，收盤後整理成每檔一個檔案，可匯出成 CSV，供事後研究盤中掛單變化。

## 在哪裡

電腦版「盤中雷達」頁上方的「當沖掃描」區塊 →「五檔錄製」分頁：錄製狀態、加錄與換股紀錄、各日紀錄，每檔可下載 CSV；設定也在這裡。

## 錄製對象

1. **推播清單**：研究名單＋自選股本來就有訂閱即時推播，直接錄製。
2. **加錄股票**：用剩下的訂閱數（保留 50 個餘裕）額外訂閱五檔，預設最多 1,000 檔。
   - 開盤前依時光機近 20 日平均成交金額挑出最活躍的一批普通股。
   - 盤中檢查點（開盤後 5 分鐘起每 30 分鐘）把幾乎沒成交的換成突然爆量、大漲跌或整個族群轉強的股票（可關閉換股）。

## 收盤整理

- 收盤集合競價結束後自動整理：今天的加錄股票（以及推播曾中斷時的全部股票）以 REST 補齊逐筆成交。
- 整理成每檔一個壓縮檔，並建立索引；收盤時沒開機的日子，下次啟動時補整理。
- 保留最近 20 個交易日（可調整 1–120 日）。

## 設定

| 設定 | 預設 |
|---|---|
| 開啟錄製 | 開 |
| 加錄檔數上限 | 1,000（0–1,900） |
| 保留天數 | 20 |
| 盤中換股 | 開 |

## 資料來源

需要富果即時推播；加錄檔數受方案訂閱上限限制（進階方案 2,000 個訂閱）。收盤補齊逐筆成交每檔 1 次 REST 請求。

## 注意事項

- 盤中錄製檔定期寫入，當機時最多遺失最後幾秒。
- 這是原始紀錄，不是訊號；衡析目前不會用錄製內容自動回測。
